PGSQL Documentation notes:
  The indexes are used to avoid sequential search O(N) runtime for searches by...
  ...tieing an index to each column. 
  ...This makes it so the item tied to the index is retrieved without having to check every column
  Skeleton code: CREATE INDEX index_variable_name ON table_name (column_name);

  Example use: SELECT * FROM users WHERE email = 'example@example.com';
  above code goes straight to the index: B-tree, hash table, etc. where the data is stored...
  ...w/o checking all the entries

The structures used for insertion, deletion, and searching in Postgres:
  B+ Trees
  Hashing 
  GIN
  GiST
  BRIN
  SP-GiST
